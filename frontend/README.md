## ✨ Key Features

- **Multi-Model Orchestration:** Support for 78+ models with automatic failover and smart routing.
- **Live Sandbox Preview:** In-browser live execution and rendering of HTML/CSS/JS with console capture.
- **Zero-Dependency Dark Glassmorphic Design:** Variable-based design system with fluid animations.
- **Prerendered & SEO-Optimized:** Prerendered creator and static pages with rich JSON-LD structured data (`SoftwareApplication`, `Person`, `AboutPage`).
- **Crawler & Bot Indexing:** Fully configured `robots.txt` and `sitemap.xml` permitting Googlebot and OAI-SearchBot.

---

## 🛠️ Tech Stack

- **Framework:** Next.js 16 (App Router), React 19
- **State Management:** Zustand
- **Animations:** Framer Motion
- **Icons:** Lucide React & Custom SVG Icons
- **Markdown & Code:** React Markdown, Rehype Highlight, Remark Math, KaTeX

---

## 🚀 Getting Started

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build

# Start production server
npm start
```
